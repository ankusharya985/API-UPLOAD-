YouTube Studio Control

The public YouTube APIs expose many Studio operations—videos, playlists, thumbnails, captions, channel data and analytics—but not literally every Studio UI action. Unsupported Studio-only actions are not fabricated.

API Video upload & metadata

Create/manage playlist resources and add uploaded videos where authorized.

API Captions

Caption tracks can be listed, inserted, updated, downloaded and deleted through the Data API.

API Analytics

Channel/video analytics can be queried with the YouTube Analytics API after the required authorization.

LIMIT Community posts

The public Data API does not provide a general current create endpoint for YouTube Community posts, so the dashboard cannot honestly claim to automate this.

LIMIT Studio-only controls

Cards/end screens, monetization controls and other Studio UI-only functions are not exposed as general public API operations.
